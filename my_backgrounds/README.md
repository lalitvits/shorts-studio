# Your own backgrounds

Put pictures in this folder. Within a few seconds they appear in the app's **Background** menus as
**"Your picture: ..."**. No restart is needed: open the Scenes step, or press **Refresh pictures** there.

- **Supported files:** JPG / JPEG, PNG, WebP, BMP, GIF (its first frame) and TIFF.
  Not supported: HEIC (iPhone photos; save as JPG first), PDF, videos.
- **Best size:** a vertical picture, 9:16 (for example 1080 x 1920). Other shapes are cropped from the centre.
- **Placement:** characters stand with their feet about 78% of the way down the picture, so leave floor there.
- **Names:** the file name becomes the name in the menu: `goa_airport.jpg` -> "Your picture: Goa airport".
  Giving a picture the same name as a built-in one (for example `kitchen.jpg`) replaces that one.
- **Changing a picture:** save over the same file and it is used from the next preview on.
- **Privacy:** pictures in this folder stay on your computer. They are not uploaded to GitHub.
